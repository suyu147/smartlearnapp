# 登录后引导式画像表单改造计划

## 一、目标

把登录后的“AI 对话式画像引导”改为“固定表单引导”：

1. 用户登录后固定弹出 3～4 屏选项 / 输入框，快速完成画像。
2. 提交后统一调用记忆能力，从用户的选择和输入中提取有效信息。
3. 有效信息写入结构化画像 `dimensions`，它是唯一权威数据源；学习路径、推荐、完成度都直接读它。
4. 同一批有效信息异步写入长期记忆，只作为 AI 对话上下文，不参与路径生成。
5. 无效信息不写入，标记为该维度“待补充”；后续 AI 对话中提到时再补，仍先写 `dimensions`，再同步记忆。

原则：`dimensions` 是唯一事实来源；长期记忆是对话上下文的副本，不是权威；无效内容宁可不存，也不要污染画像。

---

## 二、改造后的整体流程

登录成功
→ 判断是否已完成引导
→ 未完成：进入表单引导页（替换现有对话引导）
→ 用户填写 / 跳过
→ 提交后统一做一次“信息提取与有效性校验”
→ 有效维度：先写入结构化画像 `dimensions`（权威），再异步同步到长期记忆（仅对话用）
→ 无效维度：标记为“待补充”，`dimensions` 和长期记忆都不写
→ 标记引导完成，进入主页
→ 后续对话中命中待补充维度时，先更新 `dimensions`，再同步记忆
→ 学习路径、推荐、完成度直接读取 `dimensions`，无需改造即可生效

---

## 三、维度设计

### 保留（表单必采）

| 维度 | 采集方式 | 说明 |
|---|---|---|
| 身份与学段 | 单选 | 学生 / 职场 / 教师等；学段或职业 |
| 学科与领域 | 多选 + 补充输入 | 当前学习或关注的领域 |
| 现有基础 | 单选（自评）+ 输入 | 入门 / 进阶 / 高级，可补充已学内容 |
| 学习目标 | 单选 + 输入 + 日期 | 应试 / 技能 / 兴趣；目标描述；目标时间 |
| 薄弱与困难 | 多选 + 输入 | 薄弱知识点、卡点 |
| 内容形式偏好 | 多选 | 视频 / 文档 / 实操 / 练习 / 思维导图 |
| 可用时间 | 单选 + 多选 | 单次时长、常用时段 |

以上 7 项作为首屏表单维度，其中身份、学科、目标为必填，其余可跳过。

### 删除或降级（不放进表单）

| 维度 | 处理方式 | 原因 |
|---|---|---|
| 认知风格（视觉/听觉/阅读/动手） | 删除自评，改用“内容形式偏好” | 自评不准，VARK 争议大 |
| 学习节奏（快/慢） | 删除 | 自评失真，应由行为数据推断 |
| 兴趣细分领域 | 降为可选 | 首屏价值低，后期可补 |
| 易错点 / 错误模式 | 不在表单采集 | 应由错题、测验、对话自动沉淀 |
| 学习频率 | 不由用户填 | 由活跃行为统计推断 |
| 性别、精确地区等 | 不采集 | 与学习无关且涉及隐私 |

新增建议：目标时间（考试日期 / 截止日期）。目前只有目标文本，无法排学习计划。

---

## 四、表单设计

- 共 3～4 屏，每屏 1 个主题，避免长表单。
- 以选项为主、输入为辅；选择题保证数据质量。
- 每屏可“跳过”，但至少完成身份、学科、目标三项。
- 右上角保留“稍后完善”，与现有引导行为一致。
- 提交前展示一页摘要，允许返回修改。

---

## 五、提取与入库策略

### 1. 唯一权威：结构化画像 `dimensions`

- 表单选择值、日期、提取后的文本，统一写入现有画像数据结构 `dimensions`。
- 学习路径规划、资源推荐、完成度展示只读取 `dimensions`，不读取长期记忆。
- 路径生成逻辑不需要改造：`dimensions` 一更新，现有规划流程立即生效。

### 2. 长期记忆：只做 AI 对话上下文

- 长期记忆保存自然语言事实，例如“用户准备考研，偏好视频 + 练习”，供 AI 对话读取。
- 长期记忆不参与路径生成、不参与完成度计算，也不能反向覆盖 `dimensions`。
- 记忆写入失败不影响画像与路径，属于可降级的旁路。

### 3. 提取时机与写入顺序

1. 表单提交后统一调用一次记忆 / 抽取能力，不逐题调用，减少等待和成本。
2. 先写 `dimensions`，成功后立即标记引导完成。
3. 再异步写长期记忆；失败只记日志，不回滚画像、不阻塞跳转。

### 4. 提取结果按维度独立判定

每个维度返回三态：

- 有效：内容明确、与维度相关 → 写入 `dimensions`，并同步长期记忆
- 模糊：有内容但不够具体 → 可写入 `dimensions`，暂不写长期记忆，标记待确认
- 无效：空白、无关、灌水、前后矛盾 → `dimensions` 和长期记忆都不写，标记待补充

选择题值默认视为有效，只有文本字段需要判定。

### 5. 一致性与冲突处理

- `dimensions` 为准；记忆与画像冲突时，以 `dimensions` 为准。
- 同一用户重复提交时覆盖 `dimensions` 最新值，记忆按最新事实更新，不重复追加。
- 对话补全和设置页修改同样遵循“先 `dimensions`，后记忆”，不允许只写记忆不写画像。
- 记忆侧保留历史版本，但不作为业务判断依据。

---

## 六、无效信息的处理

1. 维度级状态：已确认 / 待补充 / 已跳过。
2. 无效输入只在画像元数据里记录“该维度未获取”，原始无效文本不落库、不进记忆。
3. 不因某个维度无效阻塞引导完成；完成度只按必填维度计算。
4. 后续对话中，AI 只看到“还有哪些维度待了解”，看不到无效原文。
5. 用户在对话中提到相关内容时：
   - 命中待补充维度 → 抽取 → 校验通过 → 状态改为已确认
   - 先更新 `dimensions`，再同步长期记忆；无效原文仍然不入库
   - 完成度与后续路径规划随之刷新
6. 用户主动在设置页修改画像时，同样同步更新长期记忆。

---

## 七、与现有系统的对接

- 引导入口：沿用现有登录后跳转与路由守卫逻辑，只替换引导页内容。
- 完成标记：沿用现有“画像完成时间”字段，完成判定从“8 维全填”改为“必填维度已确认”。
- 画像存储：沿用现有画像数据结构和读写接口，新增维度状态与目标时间字段。
- 学习路径：不改造。路径规划继续只读 `dimensions`，因此表单有效信息会自然进入路径生成。
- 记忆能力：沿用现有三层记忆与记忆写入接口，新增“引导问卷”来源；记忆只注入对话上下文，不进入路径接口。
- 对话补全：沿用现有对话中的画像更新与记忆写入能力，增加“待补充维度”触发条件，并保证先写画像后写记忆。
- 现有对话式引导组件可保留为“完善画像”入口，不再作为登录后默认页。

## 八、分期落地

### P0 表单化

- 新表单引导页，替换登录后默认页
- 必填校验、跳过、完成跳转
- 选择题与日期直接写入结构化画像
- 完成度改为按必填维度计算

### P1 提取与记忆

- 文本字段统一提取与有效性判定
- 维度三态与待补充机制
- 有效信息先写入 `dimensions`，再异步写入长期记忆并触发汇总
- 重复提交幂等处理

### P2 对话补全与闭环

- 对话中命中待补充维度自动补全
- 设置页画像编辑与记忆同步
- 画像完成度、推荐与学习路径直接读取最新 `dimensions`，无需额外同步
- 老用户数据迁移与兼容

---

## 九、风险与边界

- 提取失败时降级：选择题值直接写入 `dimensions`，文本仅保存原文到画像草稿，不写长期记忆。
- 防止记忆污染：无效文本一律不进入长期记忆。
- 防止两套画像分叉：长期记忆不得作为路径输入；发现冲突时以 `dimensions` 为准。
- 防止覆盖：以最新确认值为准，保留版本历史。
- 隐私：只采集学习相关信息，不采集敏感身份信息。
- 可退出：任何阶段都可跳过，后续在设置或对话中补全。

---

## 十、验收标准

1. 新用户登录后固定进入表单引导，3～4 屏内可完成或跳过。
2. 选择项写入后，画像页与推荐立即生效；下一次学习路径规划能读取到新的 `dimensions`。
3. 输入无意义内容时，该维度显示“待补充”，`dimensions` 与长期记忆中均查不到该内容。
4. 后续对话提到相关内容后，该维度自动变为已确认：先更新 `dimensions`，再同步记忆。
5. 重复提交不产生重复记忆。
6. 已完成引导的老用户不受影响，可直接进入主页。
7. 路径规划请求只依赖 `dimensions`，不读取长期记忆也能正常生成。
