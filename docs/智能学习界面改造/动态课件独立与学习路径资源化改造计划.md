# 动态课件独立与学习路径资源化改造计划

## 1. 目标

1. **动态课件独立**：智能学习页保留现有生成、展示、设置能力，但不再依赖学习路径、节点和反馈。用户输入主题（可选页数、配图、交互 HTML、随堂测验）即可生成。
2. **独立历史**：动态课件有服务端用户级历史列表，跨设备可见，可单独删除。
3. **学习路径资源化**：学习路径保留节点规划与反馈，改为按资源决策自动生成资源中心的七种资源（文档、思维导图、习题、视频、代码、扩展阅读、标准 PPT）。标准 PPT 使用默认参数自动生成。
4. **路径本期只留接口**：学习路径暂不提供前端展示页，后端接口和生成能力保留，后续接入资源列表与查看器。

## 2. 不做的事

- 不改变资源中心现有“点什么资源就生成什么资源”的生成流程。
- 不实现学习路径的资源展示页。
- 不迁移历史路径中的动态课件，旧数据保留只读。

## 3. 现状问题

- [generate-resources.ts](file:///e:/智学方舟app/smartlearn-master/lib/learning-graph/nodes/generate-resources.ts) 目前只生成动态课件，且依赖路径中的 `currentNode`；路径缺失时直接返回，静默不生成。
- 动态课件与路径强耦合：`scene_ready` / `ppt_ready` / `path_update` / 节点资源挂载 / 前端按节点过滤展示。
- 资源中心的第七种资源是**标准 PPT（可下载 pptx）**，与动态课件（Scene + 交互 HTML）不是同一产物，当前共用 `ppt` 类型但渲染方式不同。

## 4. 方案总览

```text
动态课件（独立）
输入主题 + 选项 → POST /api/v1/smartlearn/courseware（SSE）
  → generatePptScenes → 保存课件历史 → 前端逐页渲染 / 历史回放

学习路径（本期仅后端）
POST /api/v1/smartlearn（保留）
  → plan_node → plan_resources（七种资源决策）
  → generate_resources（自动生成推荐类型）
  → 保存 LearningPath + Resource + PathNodeResource
  → 资源中心可见并标记「来自学习路径」
```

## 5. 详细改动

### 5.1 动态课件独立

**前端 `app/smartlearn/page.tsx`**

- 移除路径相关逻辑：路径时间线、节点选择、按节点过滤资源、`path_update` 处理、路径完成状态更新、`nodeDecisionOverrides`。
- 保留现有能力：主题输入、设置项（页数、配图、交互 HTML、随堂测验）、SSE 流式渲染、`PPTViewer`、`streamingPpt`。
- 新增：动态课件历史列表（侧栏或抽屉），点击加载历史课件；生成完成后刷新列表。

**新增服务端接口**

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/v1/smartlearn/courseware` | 生成动态课件，SSE 推送 `scene_ready` / `ppt_ready` / `done` |
| GET | `/api/v1/smartlearn/courseware` | 当前用户课件历史列表（不含 scenes） |
| GET | `/api/v1/smartlearn/courseware/[id]` | 读取单个课件完整 scenes |
| DELETE | `/api/v1/smartlearn/courseware?id=` | 删除自己的课件 |

**生成逻辑**

- 直接复用 `generatePptScenes`（[ppt-generator.ts](file:///e:/智学方舟app/smartlearn-master/lib/learning-graph/helpers/ppt-generator.ts)），不经过 learning-graph。
- 入参：`topic`、`options`、`aiConfig`；不接收 `sessionId`、`nodeId`、`currentNode`。
- 按 `userId` 隔离，接口只允许读写当前登录用户的数据。

**存储**

- 复用 `Resource` 表：`type='ppt'`、`sourceAgent='smartlearn-courseware'`、`sessionId=null`。
- `metadata = { knowledgePoints: [topic], coursewareData: scenes, options }`。
- 资源中心查询时排除 `sourceAgent='smartlearn-courseware'`，保证动态课件只出现在独立历史中。
- 不新增数据表；如后续需要彻底隔离再迁移到独立表。

### 5.2 学习路径资源化

**资源决策**

- [resource-decision.ts](file:///e:/智学方舟app/smartlearn-master/lib/generation/resource-decision.ts) 保留七种类型。
- `ppt` 语义从“动态课件”改为“标准 PPT（可下载 pptx）”。

**生成节点 `generate-resources.ts`**

- 删除 `generatePptResource`、`generatePptScenes` 调用及相关 `scene_ready` / `ppt_ready` 事件。
- 六种非 PPT 资源调用 `generateResource(type, node.knowledgePoints, profile, aiConfig)`（[resource-generators.ts](file:///e:/智学方舟app/smartlearn-master/lib/learning-graph/helpers/resource-generators.ts)）。
- 标准 PPT 调用 `generateStandardPptOutline` + `generateStandardPptDeck`（[standard-ppt.ts](file:///e:/智学方舟app/smartlearn-master/lib/generation/standard-ppt.ts)），默认参数：
  - `slideCount: 8`
  - `language: 'zh-CN'`
  - `style: 'professional'`
  - `includeImages: false`
  - `topic: node.title`（或知识点拼接）
- 生成并发限制为 2–3，逐个推送 `resource_delta`，最后推送 `path_update`。

**服务端持久化（本期无前端）**

路径生成接口需要直接落库：

1. 保存 `LearningPath`：`id = sessionId`，写入 `nodes` / `edges`。
2. 保存 `Resource`：`sessionId = sessionId`，`metadata.origin = 'learning-path'`，`metadata.nodeId = node.id`。
   - 六种普通资源：`sourceAgent = 'learning-path'`。
   - 标准 PPT：`sourceAgent = 'resource-ppt'`，保证资源中心使用 `StandardPptViewer`。
3. 建立 `PathNodeResource(pathId, nodeId, resourceId)` 关联。
4. 删除路径资源时继续清理 `PathNodeResource`，避免外键约束。

**接口保留**

- `POST /api/v1/smartlearn`：路径开始 / 下一节点。
- `POST /api/v1/smartlearn/resources`：指定 `currentNode` 生成资源。
- 本期前端不调用，等路径展示页完成后接入。

**反馈**

- 保留 `resourceFeedback` 和 `nodeDecisionOverrides` 入参与决策逻辑。
- 本期没有前端采集入口，反馈通过接口手动传入。

### 5.3 资源中心

- 保持现有七种卡片的生成流程不变。
- 列表对 `metadata.origin === 'learning-path'` 的资源显示「来自学习路径」标签。
- 动态课件（`sourceAgent='smartlearn-courseware'`）不出现在资源中心。

## 6. 分阶段实施

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0-1 | 动态课件独立接口 + 存储 + 历史列表 | 无路径、无会话也能按主题生成；刷新/换设备可见历史 |
| P0-2 | 路径改为生成七种资源 + 服务端持久化 | 路径接口生成七类资源并落库，不再产生动态课件 |
| P0-3 | 智能学习页移除路径 UI；资源中心增加来源标签与课件过滤 | 页面只保留动态课件；资源中心可见路径资源并带标签 |
| P1 | 路径展示页（资源列表 + ResourceViewer/StandardPptViewer）与反馈采集 | 节点资源可浏览，反馈可回传决策引擎 |

## 7. 验收标准

- 动态课件生成只依赖主题和选项，不再读取 `path`、`currentNode`、`nodeDecisionOverrides`、`resourceFeedback`。
- 动态课件历史按 `userId` 隔离，支持列表、查看、删除。
- 学习路径不再调用 `generatePptScenes`，不再产生 `scene_ready` / `ppt_ready`。
- 路径生成的七种资源写入 `Resource` 表并关联到节点，资源中心可见且标记来源。
- 资源中心现有七种资源的生成、查看、删除行为不变。
- 旧路径历史数据可正常读取，不因改造报错。

## 8. 风险与待确认

1. **旧动态课件数据**：历史路径中的动态课件（`sourceAgent='ppt'`、`sessionId` 非空）不迁移到新历史，仅保留只读；如需迁移需单独处理。
2. **路径生成成本**：七种资源按推荐自动生成仍可能较慢，建议保持“决策推荐 + 并发 2–3 + 标准 PPT 默认 8 页”。
3. **路径无触发入口**：本期路径只留接口，没有页面触发；后续接入页面或定时任务时再调用。
4. **类型语义**：路径中的 `ppt` 从此代表标准 PPT，动态课件不再参与路径决策，需在文档和常量命名上区分。
