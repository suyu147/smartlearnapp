# 跨设备学习历史

适用范围：改造后新建的正式记录。草稿、撤销栈、运行日志不在同步范围；旧浏览器缓存不自动迁移。用户需要在不同设备访问同一服务端并使用同一账号。进入页面、窗口恢复焦点、网络恢复时刷新；不提供离线编辑或实时协同承诺。

## 数据与行为

- 学习会话复用 `DtSession`，`mode=smartlearn`，带 `revision`、删除标记和会话快照。路径与资源分别保留数据库记录并关联 session。会话快照包含导师消息、资源反馈/偏好/决策及路径进度。
- 写入通过会话版本校验，路径、资源和会话在一个事务里更新；读取通过同一事务快照加载，避免混入不同版本。删除为软删除，旧设备不能用旧快照重新创建该 ID。冲突提示刷新，不强制覆盖其他设备的更新。
- 独立资源 `sessionId=null`，资源中心按账号列出；按会话读取可用 `/api/v1/resources/sync?sessionId=...`。资源中心删除和重新生成会提升相关学习会话版本。
- AI 对话使用服务端会话列表与消息详情，支持切换、继续、重命名、删除和分页；图片附件随消息保存。手动导入明确确认后写入数据库，不自动上传旧 localStorage。
- 画像会话/归档保存在账号历史文档，画像维度以 `LearningProfile` 为准，新的维度变化保存版本记录；画像页提供历史版本查看。答题提交即保存，画像页分页显示答题记录和错题。
- 笔记使用账号历史文档存储；编辑更新原记录，时间戳校验拒绝过期编辑。共写使用文档版本校验，AI 编辑历史归属文档账号；切换文档、离开页面前提交待保存内容，关闭页面时提示未完成保存。书籍使用版本及操作锁保护修改、阅读和书内测验进度。
- 知识库、书籍正文/页面和上传附件继续使用已有服务端基础；原文件提供带归属检查的下载接口。部署必须持久化数据库及 `DT_DATA_DIR`（默认 `data/`），多实例必须共享文件目录。
- PPT 生成图片保存为自包含 data URL，避免保存第三方临时地址。外部教学视频仍引用来源平台 URL，资源历史可恢复，但第三方下架的视频无法由本项目恢复。
- PPT 最大页数、互动/测验开关及现有普通偏好通过服务端设置接口保存，支持 null 恢复默认和版本冲突检查。API 密钥不作为普通设置明文跨设备同步；现有加密 API-key 服务保持独立。

## 接口

- `GET/PUT/DELETE /api/v1/learning-history`：会话快照/版本校验/删除。
- `GET/PUT /api/v1/history/profile`：画像对话、归档及版本。
- `GET/POST /api/v1/quiz-attempts`：分页答题明细、幂等提交。
- `GET/POST /api/v1/sessions` 与详情接口：AI 会话列表、创建、消息分页、更新、删除。
- `POST /api/v1/book/progress`：阅读和书内练习进度。
- 旧 `/api/v1/user/sync` 批量上传返回 410，避免无归属、无版本的旧缓存覆盖新记录。

## 部署

代码与新增数据库字段需要一起部署。先备份数据库，再在目标服务端执行：

```sh
npx prisma migrate deploy
npx prisma generate
npm run build
```

新增迁移：`20261126000000_cross_device_history`。本次已在本机 localhost:5432/smartlearn 应用；其他环境仍需自行部署迁移。

新缓存使用 `*-cloud-v1` 命名，不读取旧学习历史缓存。完整会话、消息、画像和资源仅在内存缓存，不重复写入受配额限制的 localStorage，避免 PPT 配图/图片附件过大导致保存失败。只有新正式记录会进入新的同步链路。账号变更清空内存缓存，响应返回前再次核对账号，避免迟到请求污染其他账号。

## 验证

- `node node_modules/typescript/bin/tsc --noEmit --incremental false`
- `npm test`
- 设置 `HISTORY_INTEGRATION=1` 后运行 `vitest run lib/history/__tests__`：真实 PostgreSQL 创建随机测试账号，结束时仅清理这些账号的数据。
- `playwright test --config=e2e/history.config.ts`：两个独立浏览器环境模拟同一后端，验证路径切换、修改/删除传播、旧缓存不导入、AI 消息切换和共写切换/离开页面保存。生产模式可先构建，再设置 `HISTORY_E2E_PRODUCTION=1` 运行。测试使用模拟 API；真实数据持久化和归属由数据库集成测试验证。
